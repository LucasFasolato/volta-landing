# VOLTA Corporate — Roadmap

Corporate improves representation, trust transfer and routing. It does not accumulate product features.

## Now

Maintain the founder-authorized **Corporate v1** baseline: five chapters, an editorial directory, three local product demonstration showcases, concise principles, a prioritized development chapter and one closing. [CURRENT_STATE](CURRENT_STATE.md) owns the current public treatment; do not duplicate another lifecycle table here.

Use `Product selected` to establish a routing baseline. Observe whether visitors understand product differences and development labels. Do not claim acquisition or comprehension gains from implementation quality alone.

Keep the static runtime, dependencies, responsive experience, media provenance and metadata healthy. Consolidate one verified production release per coherent package instead of using Vercel previews as an editing loop. Freeze aesthetic iteration absent a documented defect or actual evidence.

## Next

- Reconcile after material product/portfolio changes, using Strategy for classification and each product for capabilities and destinations.
- Make small evidence-led improvements if visitors select the wrong product or cannot explain VOLTA.
- Replace demonstration imagery with authorized representative application captures or case studies only when the source, purpose and publication permission support it.
- Adopt a centrally approved symbol/wordmark when that separately controlled brand deliverable is ready.

## Later

Promote Shield, Bridge or Automate into available-product navigation only after authoritative readiness and Brand/Strategy decisions support it. A deployed prototype is insufficient.

Consider build-time portfolio synchronization only if repeated drift justifies it. Do not add runtime coupling, shared identity or a content backend for hypothetical needs.
