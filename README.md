# VOLTA Corporate

Sitio corporativo del ecosistema VOLTA.

## Responsabilidad

Este repositorio presenta qué es VOLTA, comunica sus productos y dirige a cada solución. **No es un producto SaaS independiente** y no debe convertirse en una fuente paralela de verdad sobre Store, Booking, Portfolio u otros productos.

La definición global de marca, principios, gobierno y registro de productos vive en `volta-os`.

## Stack

- Next.js App Router
- TypeScript
- Tailwind CSS
- Vercel

## Operating context

Read `AGENTS.md` and `docs/CURRENT_STATE.md` before substantial work.

The corporate site must stay aligned with:

- `volta-os/core/VOLTA.md`
- `volta-os/core/BRAND.md`
- `volta-os/core/DESIGN-SYSTEM.md`
- `volta-os/ecosystem/PRODUCTS.md`
- `volta-os/ecosystem/REGISTRY.yaml`

## Development

```bash
npm install
npm run dev
```

Use the repository's available type/lint/build checks before shipping. Visual changes require desktop/mobile verification.
