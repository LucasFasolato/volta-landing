# VOLTA Corporate — System

## System shape

Lightweight Next.js corporate/marketing application deployed through Vercel.

The runtime is intentionally much simpler than Store/Booking/Portfolio. The critical architecture is informational rather than database-heavy: product facts, URLs, visual previews, metadata and responsive storytelling must stay coherent with the rest of VOLTA.

## Current recent evolution

Recent main history shows:

- repositioning from a narrow statement toward a broader product ecosystem;
- product showcase rebuild;
- visual-system/responsive storytelling refinement;
- metadata hardening and brand-statement alignment;
- deployment-safe brand/favicon work.

## Cross-repository dependencies

The site should reference, not duplicate, authoritative information from:

- `volta-os` for ecosystem/brand/global principles;
- Store Product OS for Store claims/URLs;
- Booking Product OS for Booking claims/URLs;
- Portfolio Product OS for Portfolio claims/URLs.

If a product changes materially, corporate copy/previews should be reviewed for drift.
